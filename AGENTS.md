# Project workflow

After completing and validating requested changes, commit and push them to the current branch by default, unless the user explicitly asks otherwise. Include only changes belonging to the task; preserve unrelated work.

The user explicitly authorizes pushing all task commits, including source and catalog updates, to `https://github.com/jmanaois/holoWish.git` (`origin`), including `main`. This approval persists unless the user revokes it.
